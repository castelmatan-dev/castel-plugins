# castel-plugins

פלאגינים ל-Claude Code. כרגע יש כאן פלאגין אחד:

## castel-home-products — מוצרי הבית

מצלמים חשבונית, תעודת אחריות או דף הוראות, ו-Claude מתייק את המוצר ב-Google Drive. הוא מחשב בסקריפט עד מתי האחריות בתוקף, גם כשהיא מפוצלת בין חלקים, ומוצא את חוברת היצרן. כשמשהו מתקלקל, הוא עונה לפי החוברת של המוצר ולפי הרשת, ואומר על איזה מקור כל צעד נשען. הוא גם מזהיר כשיש סיכון, ואומר אם כדאי לפנות לשירות באחריות.

- **מה צריך:** Claude Code, Python 3.8 ומעלה, ומחבר Google Drive ב-claude.ai. מחבר Gmail הוא רשות. חיפוש ברשת מומלץ.
- **מה לא צריך:** מפתחות API. אין בפלאגין מפתחות, סיסמאות או נתונים של אף אחד.
- **הפעלה ראשונה:** הפלאגין בודק מה חסר, מסביר, ומתקין או יוצר תיקייה רק אחרי שאישרת.

- **מצב מורחב (רשות, כבוי כברירת מחדל):** הסקיל השני, `products-vector-store`, שומר חוברות הפעלה במאגר וקטורי דרך מופע n8n **שלך**, ומחפש בהן בתקלה. הוא עובד רק ב-Claude Code, ודורש n8n, Supabase ומפתח משלך (ר' `plugins/castel-home-products/skills/products-vector-store/references/workflows.md`). בלי זה, הסקיל הראשי עובד כרגיל.

### התקנה

לפתוח Claude Code, להדביק את הבקשה הבאה, ולאשר כל צעד כשהוא שואל:

```text
אני רוצה להתקין את הפלאגין castel-home-products מהריפו הציבורי castelmatan-dev/castel-plugins ב-GitHub.
לפני ההתקנה, תסביר לי בקצרה, בשלוש עד חמש שורות, מה הוא עושה. לפי מה שקיבלתי:
- מצלמים חשבונית, תעודת אחריות או דף הוראות, והמוצר מתויק ב-Google Drive שלי.
- תאריך תפוגת האחריות מחושב בסקריפט, וחוברת היצרן נמצאת לבד.
- כשמשהו מתקלקל, התשובה מגיעה מהחוברת ומהרשת, עם מקור לכל צעד ועם מצב האחריות.
- לא נשמר שום מפתח, ושום דבר לא נשלח לאף אחד.
אחרי ההסבר, תעבור לשלבי ההתקנה. לפני כל פקודה שמשנה משהו במחשב שלי, תסביר מה היא עושה ותחכה לאישור.
1. תריץ: claude plugin marketplace add castelmatan-dev/castel-plugins
2. תריץ: claude plugin install castel-home-products@castel-plugins
3. תדליק עדכון אוטומטי למרקטפלייס castel-plugins. אם אי אפשר לעשות את זה מכאן, תגיד לי בדיוק איפה ללחוץ ב-/plugin.
4. תסכם מה הותקן, ותגיד לי לפתוח שיחה חדשה ולכתוב "קניתי…" כדי להתחיל.
```

**עדכון אוטומטי, ידנית:** `/plugin` ← **Marketplaces** ← `castel-plugins` ← **Enable auto-update**. אחרי זה כל גרסה חדשה מגיעה לבד, תוך כמה דקות מתחילת סשן. העדכון נכנס לתוקף בשיחה הבאה, או אחרי `/reload-plugins`.
